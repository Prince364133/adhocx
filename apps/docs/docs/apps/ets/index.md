applications, not a standalone application.

## Historical and proposed material

Older ETS documents include product requirements, target designs, proposed
DDD structures, dated audits and completion plans. Their original paths are
preserved for traceability, but they are not current implementation
documentation by default:

- [Historical specifications and audit snapshots](./historical-archive.md)
- [Roadmaps and target-state plans](./roadmap-archive.md)

Read the status matrix before using an older specification as an operating
rule. Product/technical claims that differ from current code are identified
there as unresolved or historical.
