# Documentation Application

## Functional Perspective

The Docusaurus application is the single browser documentation site for
developers, operators, administrators and product users. It explains project
scope, applications, routes, modules, features, APIs, database models and
workflows using the existing AdhocX design language.

## Technical Perspective

The documentation application is in `apps/docs`. `docusaurus.config.ts`
defines the title, base URL, generated sidebars, theme CSS and API Swagger link.
`sidebars.ts` uses autogenerated navigation. Markdown pages live under
`docs/apps` and `docs/platform`; `**/internal/**` content is excluded from the
public build.

The custom landing and cards are in `src/pages/index.tsx` and
`src/css/custom.css`. A production build is run with:

```bash
pnpm --filter @adhocx/docs run build
```
