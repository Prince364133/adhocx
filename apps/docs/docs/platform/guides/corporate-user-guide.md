# Corporate User Guide

**Evidence status:** Verified for implemented portal areas and API-backed
support workflows.

## Who Uses This Guide

- Corporate transport managers
- Corporate administrators
- HR and finance roles
- Corporate safety and read-only users

## Sign In

1. Open the Corporate Portal.
2. Choose password or OTP login.
3. Sign in with an account linked to a corporate tenant.
4. The portal loads tenant and office context.

The account must belong to a corporate role and tenant. A valid account with
the wrong role cannot use the Corporate Portal.

## Main Areas

| Area | Typical use |
|---|---|
| Dashboard | Shift, live commute and exception overview |
| Routes | Route list, detail and live trip state |
| Employees | Employee directory and transport eligibility |
| Rosters | Import, validate, approve and publish |
| Cancellations | Transport change requests |
| Support | Ticket creation, replies and history |
| Billing | Invoice and dispute review |
| Reports | Usage, costs, fleet and performance |
| Company Profile | Organization and office configuration |

## Roster Upload

1. Open Roster Import.
2. Download or prepare the roster template.
3. Upload a supported XLSX/CSV file.
4. Review validation results.
5. Approve and publish the roster.
6. Review generated transport requests.

Publishing should only proceed after employee, office, shift and location
validation is complete.

## Route Review

Use route detail pages to review:

- Stop sequence
- Passenger manifest
- Driver and vehicle
- Route status
- Live position
- Timeline and tracking history

Route edits and overrides should be performed only by authorized roles.

## Support

Create a ticket with:

- Category
- Subject
- Description
- Priority
- Optional employee context
- Supported image attachments

After creation, use the ticket detail view to track status and reply.
