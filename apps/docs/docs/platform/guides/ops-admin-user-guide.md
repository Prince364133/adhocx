# Ops and Admin User Guide

**Evidence status:** Verified against the Ops and Admin shell and support
routes.

## Ops User

Use Ops for:

- Live dispatch and fleet monitoring
- Route and stop review
- Driver reassignment
- Safety/SOS response
- Incident escalation
- Support ticket updates
- Corporate tenant operations

### Daily Operations

1. Sign in with an OPS or ADMIN account.
2. Select a corporate tenant where required.
3. Open Live or Dashboard.
4. Review at-risk routes and stale telemetry.
5. Investigate and reassign where policy permits.
6. Record operational updates and close incidents.

### SOS Response

1. Open active SOS alerts.
2. Acknowledge promptly.
3. Investigate route, stop and telemetry context.
4. Escalate or close with audit notes.
5. Choose resolved or false-alarm outcome when closing.

## Admin User

Use Admin for:

- Driver/vendor verification
- Users and companies
- Pricing and reports
- Corporate configuration
- Finance and settlements
- Disputes and support
- Feature flags and audit logs

## Support Handling

Support desks are role-based:

- Corporate/employee tickets
- On-demand marketplace disputes
- Ops ticket updates
- Internal/admin ticket messages

Add resolution notes and public/internal comments according to the support
workflow. Internal notes should not be sent as public replies.
