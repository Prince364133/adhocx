# AdhocX Glossary

| Term | Canonical definition |
|---|---|
| AdhocX | B2B commercial mobility platform for marketplace fulfillment and enterprise transportation |
| API | The NestJS modular monolith under `apps/api` |
| Assignment | The relationship between a requirement/trip and an accepted driver |
| Admin | Next.js platform governance and compliance application |
| Corporate | Next.js portal used by corporate transport administrators |
| Corporate Tenant | An organization with isolated corporate employees, offices and transport configuration |
| Dispatch | Matching and assigning eligible drivers to requirements or corporate routes |
| DigiO | Third-party KYC and verification integration used for identity and document checks |
| Driver | A verified person and vehicle supply participant |
| Employee App | Flutter application used by corporate commuters |
| ETS | Enterprise Transportation System business domain implemented across Corporate, Employee, Ops, Mobile and API |
| Fulfillment | Process of satisfying a vendor requirement or corporate route |
| Ledger | Accountable debit or credit records for wallet and financial activity |
| Marketplace | On-demand commercial cab sourcing and fulfillment model |
| Mobile | Flutter vendor/driver application |
| Offer | A dispatch proposal sent to an eligible driver |
| Ops | Next.js operations and safety command application |
| Requirement | A vendor-created request for one or more vehicles or trips |
| Roster | Employee commute shift and pickup/drop demand schedule |
| Route | A planned or executed vehicle journey containing ordered stops |
| SOS | Safety escalation request from a driver or employee |
| Stop | A pickup or drop location within a corporate route |
| Tenant | Corporate organizational boundary used for authorization and data isolation |
| Trip | The executed lifecycle of an assignment or corporate route request |
| Trip Event | Timestamped state or telemetry record associated with trip execution |
| Vendor | User organization that creates requirements and manages fulfillment |
