# Master Documentation Progress

This is the historical tracker for the original 20-phase documentation
foundation program. "Delivered (historical)" means the listed page group was
produced and a build was recorded at that time; it does not mean every route,
feature, API contract or data model is fully documented. The later audit and
active completion work are tracked in
`apps/docs/docs/platform/internal/documentation-completion-implementation-plan.md`.
This internal tracker is excluded from the public Docusaurus build.
